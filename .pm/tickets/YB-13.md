# Description


[Claude Sonnet 4.6]

## Problem Statement
The Spanish Standard layout must be seeded as a `LanguageModule` as specified in SPEC §6.2. It passes most keys through as-is (it's primarily an accent helper) and remaps `;` → `ñ`.

## Solution Approach
Create `modules/spanish.go` containing the `SpanishModule` variable populated verbatim from the spec.

## Data (from SPEC §6 — reproduce exactly)
- `ID`: `"spanish"`, `Name`: `"Spanish Standard"`, `Enabled`: `true`
- `DirectMap`: 30 entries including letter pass-throughs and `;` → `ñ`
- `ShiftDirectMap`: 30 entries including `:` → `Ñ` and symbol remaps
- `PhoneticMap`: 8 entries for accented vowels, ñ, ç, ¡, ¿
- `KeyboardRows`: 4 rows, **must match `StandardRowLengths = [13, 13, 11, 10]`** exactly. The spec provides [10, 10, 10, 8] — the following physical keys are absent and must be filled with `EmptyKey()`:
  - Row 0 (number): `` EmptyKey("`") ``, `EmptyKey("-")`, `EmptyKey("=")`
  - Row 1 (QWERTY): `EmptyKey("[")`, `EmptyKey("]")`, `EmptyKey("\\")`
  - Row 2 (home):   `EmptyKey("'")`
  - Row 3 (bottom): `EmptyKey(",")`, `EmptyKey(".")`, `EmptyKey("/")`

## Implementation Steps
- [ ] Create `modules/spanish.go`
- [ ] Declare `var SpanishModule = LanguageModule{...}` matching SPEC §6.2 exactly
- [ ] Populate `DirectMap` (30 entries)
- [ ] Populate `ShiftDirectMap` (30 entries)
- [ ] Populate `PhoneticMap` (a→á/ä, e→é, i→í, o→ó, u→ú/ü, n→ñ, c→ç, h→¡/¿)
- [ ] Populate `KeyboardRows` (4 rows, totals must be [13, 13, 11, 10]) inserting `EmptyKey()` for unremapped positions (9 keys listed above)
- [ ] Call `ValidateModule(SpanishModule)` in a test or init — must return `nil`
- [ ] Register `SpanishModule` in the model's `languages` slice in `main.go`
- [ ] Confirm `go vet ./...` passes

## Acceptance Criteria
- [ ] `SpanishModule` compiles with correct types
- [ ] Pressing `;` in DirectMode produces `ñ`
- [ ] Pressing `Shift+:` produces `Ñ`
- [ ] In SearchMode, query `"h"` yields candidates `¡ ¿`
- [ ] Keyboard grid row 0 is the number row `1!  2@  3#  …`
- [ ] Module is enabled by default (`Enabled: true`)

## Edge Cases
- Spanish DirectMap passes most letters through unchanged — this is intentional; the value of this module is PhoneticMap for accent selection
- Number row keys in `KeyboardRows` have standard `Normal`/`Shift` pairs (digits and symbols); they should not be in `DirectMap` unless the spec includes them
