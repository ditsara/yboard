# Description


[Claude Sonnet 4.6]

## Problem Statement
Users need to switch between enabled language modules using F3 (previous) and F4 (next) without entering the setup screen. The switch must wrap around and skip disabled modules.

## Solution Approach
In `updateTyping`, handle `key.Type == tea.KeyF3` and `key.Type == tea.KeyF4`. Walk `m.languages` in the appropriate direction, skipping entries where `Enabled == false`, with wrap-around.

## Navigation Logic
```go
func prevEnabledLanguage(m model) model {
    n := len(m.languages)
    for i := 1; i <= n; i++ {
        idx := (m.activeIndex - i + n) % n
        if m.languages[idx].Enabled {
            m.activeIndex = idx
            return m
        }
    }
    return m  // no change if none enabled
}

func nextEnabledLanguage(m model) model { /* same, +i direction */ }
```

## Keybindings
| Key | Action |
|-----|--------|
| F3 | Select previous enabled language (wrap around) |
| F4 | Select next enabled language (wrap around) |

## Implementation Steps
- [ ] Implement `prevEnabledLanguage(m model) model`
- [ ] Implement `nextEnabledLanguage(m model) model`
- [ ] Wire F3 → `prevEnabledLanguage` in `updateTyping`
- [ ] Wire F4 → `nextEnabledLanguage` in `updateTyping`
- [ ] Update `viewTyping` to display the active language name (already in YB-5 mode badge)
- [ ] Set a transient `statusMessage` on switch: `"🌐 Switched to Thai (Kedmanee)"`
- [ ] Clear `searchQuery` when switching languages

## Acceptance Criteria
- [ ] F4 cycles forward through enabled languages and wraps from last to first
- [ ] F3 cycles backward through enabled languages and wraps from first to last
- [ ] Disabled modules are skipped entirely
- [ ] If only one language is enabled, F3/F4 are no-ops (or show same language)
- [ ] Active language name in the mode badge updates immediately
- [ ] `searchQuery` is cleared on language switch

## Edge Cases
- If all languages are disabled (zero enabled): F3/F4 do nothing, `activeIndex` unchanged
- `activeIndex` may point to a now-disabled module after the user disables it in Setup; on re-entry to typing view, snap `activeIndex` to the first enabled module (or show warning if none)
